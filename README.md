# CHAT TEKIRESPONDE
## Introdução
Nessa seção você encontrará as informações do código frontend do projeto tekiresponde e a tabela para instalação do backend necessário
## 1- Crie um Schema no mysql de acordo com sua preferência
Além disso, não se esqueça das seguintes etapas:
+ modifique sua senha
+ modifique seu usuário

Após tal processo, adeque suas mudanças nos arquivos conn.js e bd.py
## 2- Execute o arquivo bd.py na pasta python 
Caso não tenha instalado as bibliotecas, o faça antes. 
## 3- Rode no Mysql o código comentário qdisponibilizado na pasta python
Não esqueça de adequar o nome ao seu schema!
## 4- Baixe as bibliotecas node
Caso não tenha instalado
## 5- Use NPM start e veja a aplicação!
Agradecemos pela atenção!
